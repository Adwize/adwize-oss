# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in adwize-oss, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email **security@getadwize.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your report within 48 hours and aim to release a fix within 7 days for critical issues.

## Scope

This policy covers the open-source Adwize stack in this repository: API, worker, CLI, MCP server, and their dependencies. It does **not** cover the hosted Adwize platform at app.getadwize.com (report those separately to the same address and say they are hosted-product issues).

## Supported Versions

| Version | Supported |
|---------|-----------|
| `main` / latest release | Yes |
| Older published tags | Best effort |
